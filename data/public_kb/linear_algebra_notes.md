# 线性代数要点笔记：特征值与矩阵分解

## 一、矩阵基本运算

**矩阵乘法**：A(m×n) 与 B(n×p) 相乘得到 C(m×p)，要求左矩阵的列数等于右矩阵的行数。矩阵乘法不满足交换律，一般 AB ≠ BA，但满足结合律与分配律。

**转置**：(AB)ᵀ = BᵀAᵀ。对称矩阵满足 Aᵀ = A，实对称矩阵的特征值必为实数且特征向量可取为正交的。

**逆矩阵**：方阵 A 可逆的充要条件是行列式 |A| ≠ 0，等价于秩满秩。逆矩阵满足 (AB)⁻¹ = B⁻¹A⁻¹。

**秩**：矩阵中线性无关的行（或列）的最大个数。秩反映了矩阵所代表的线性变换的「有效维数」。秩亏意味着变换会压缩维度，该变换不可逆。

## 二、行列式

行列式是方阵的一个标量函数，几何意义是线性变换对体积的缩放倍数。|A| = 0 表示变换把空间压缩到更低维，因此不可逆。

二阶行列式：|A| = ad − bc。三阶及以上可用代数余子式展开或高斯消元化为三角阵后求对角线乘积。

行列式的性质：交换两行变号；某行加上另一行的倍数不变；上三角矩阵的行列式等于对角线元素之积。

## 三、特征值与特征向量

若存在非零向量 x 使得 **Ax = λx**，则称 λ 为矩阵 A 的特征值，x 为对应的特征向量。几何意义是：线性变换 A 作用在特征向量上，只改变长度（缩放 λ 倍），不改变方向。

**求解方法**：由 (A − λI)x = 0 有非零解，得特征方程 **det(A − λI) = 0**。展开后是关于 λ 的多项式，其根即特征值。

**二阶速记**：对 2×2 矩阵 A，特征多项式为 **λ² − tr(A)λ + det(A) = 0**，其中 tr(A) 为迹（对角线元素之和）。于是两个特征值满足 λ₁ + λ₂ = tr(A)，λ₁λ₂ = det(A)。

**性质**：矩阵所有特征值之和等于迹，所有特征值之积等于行列式。三角矩阵的特征值就是对角线元素。

## 四、相似对角化

若存在可逆矩阵 P 使得 **P⁻¹AP = Λ**（Λ 为对角阵），则称 A 可对角化，Λ 的对角线元素就是特征值，P 的列是对应的特征向量。

判据：n 阶矩阵可对角化的充要条件是有 n 个线性无关的特征向量。

**实对称矩阵**一定可以正交对角化：存在正交矩阵 Q 使得 QᵀAQ = Λ，且属于不同特征值的特征向量自动正交。这是谱定理的内容，也是 PCA 的理论基础。

## 五、奇异值分解 SVD

任意 m×n 实矩阵 A 都可以分解为

**A = UΣVᵀ**

其中 U 是 m×m 正交矩阵，V 是 n×n 正交矩阵，Σ 是 m×n 的对角矩阵，对角线元素称为奇异值，非负且按降序排列。奇异值是 AᵀA 的特征值的平方根。

几何解释：SVD 把任意线性变换拆成三步——先旋转（Vᵀ），再沿坐标轴缩放（Σ），最后再旋转（U）。

**应用**：降维（保留前 k 个奇异值做低秩近似）、推荐系统、图像压缩、求伪逆、潜在语义分析。截断 SVD 保留了矩阵的主要能量，是最小二乘意义下的最优低秩近似。

## 六、投影与最小二乘

向量 b 在子空间 W 上的投影是 W 中距离 b 最近的点。若 W 由矩阵 A 的列空间张成，则投影矩阵为 **P = A(AᵀA)⁻¹Aᵀ**。

最小二乘问题 min ‖Ax − b‖² 的解满足正规方程 **AᵀAx = Aᵀb**，当 AᵀA 可逆时 x = (AᵀA)⁻¹Aᵀb。这就是线性回归闭式解的来源。

## 七、范数与内积

**内积**：⟨x, y⟩ = xᵀy，衡量两个向量的夹角关系。夹角余弦为 cos θ = xᵀy / (‖x‖‖y‖)。

**常用范数**：L1 范数为各分量绝对值之和；L2 范数为欧氏长度；L∞ 范数为最大分量绝对值。L1 产生稀疏性，L2 平滑且可导。

**正交**：内积为零的向量互相垂直。正交向量组线性无关，是构造基的便利工具。

## 八、常见考点提示

1. 判断矩阵是否可逆：行列式、秩、特征值是否含 0 三种等价视角。
2. 求特征值与特征向量：先解特征方程，再解齐次方程组。
3. 判断可对角化：统计每个特征值的几何重数（对应特征子空间维数）是否等于代数重数。
4. 用 SVD 做低秩近似：保留前 k 个奇异值，写出近似矩阵。
5. 用正交投影解释最小二乘：理解「残差与列空间正交」的几何含义。
