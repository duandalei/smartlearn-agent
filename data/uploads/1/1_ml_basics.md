# 机器学习核心概念速览

## 一、三种学习范式

**监督学习**：从带标签的数据中学习输入到输出的映射。回归任务输出连续值（如房价预测），分类任务输出离散类别（如垃圾邮件识别）。训练集上拟合得好、测试集上泛化得好，两者的权衡是模型选择的核心。

**无监督学习**：从无标签数据中发现结构。聚类（K-Means、层次聚类、DBSCAN）寻找自然分组；降维（PCA、t-SNE、SVD）在保留主要信息的前提下压缩维度。

**强化学习**：智能体与环境交互，通过奖励信号学习策略。核心要素是状态、动作、奖励、策略与价值函数。

## 二、偏差与方差

模型的泛化误差可分解为偏差、方差与不可约噪声三部分。

**欠拟合**对应高偏差：模型容量不足，训练集和测试集表现都差。解决方向是增加特征、提高模型复杂度、减少正则化强度。

**过拟合**对应高方差：训练集表现好、测试集差。解决方向是增加数据、数据增强、正则化（L1/L2）、Dropout、早停、降低模型复杂度。

L1 正则化倾向产生稀疏解，可用于特征选择；L2 正则化使权重趋向于小值，防止单个特征主导。

## 三、经典监督学习模型

**线性回归**：假设输出是输入的线性组合，用最小二乘法求解，闭式解为 w = (XᵀX)⁻¹Xᵀy。当 XᵀX 不可逆时可用岭回归加入正则项。

**逻辑回归**：在线性组合上套 Sigmoid 函数把输出压缩到 (0,1)，用交叉熵损失训练，是二分类的基线模型。

**决策树**：按信息增益、信息增益率或基尼指数选择划分特征，递归分裂。单棵树容易过拟合，需要剪枝。

**随机森林**：对样本和特征做双重随机采样训练多棵树，通过投票或平均降低方差。

**梯度提升树 GBDT**：串行训练，每棵树拟合前一轮的残差。XGBoost 与 LightGBM 是其工程优化版本，在结构化数据上表现很强。

**支持向量机 SVM**：寻找最大间隔超平面。线性不可分时通过核函数映射到高维空间，常用核有 RBF、多项式核。软间隔引入松弛变量容忍少量误分类。

**K 近邻 KNN**：惰性学习，按距离最近的 K 个样本投票，K 的取值影响平滑程度。

**朴素贝叶斯**：假设特征条件独立，用贝叶斯公式计算后验概率，文本分类上简单有效。

## 四、模型评估

**混淆矩阵**：真正例 TP、假正例 FP、真负例 TN、假负例 FN。

**精确率与召回率**：精确率 = TP/(TP+FP)，衡量预测为正的样本里有多少真的为正；召回率 = TP/(TP+FN)，衡量真正为正的样本里被找出了多少。F1 是两者的调和平均。

**ROC 曲线与 AUC**：以假正例率为横轴、真正例率为纵轴绘制，AUC 衡量排序能力，对类别不平衡不敏感。

**交叉验证**：K 折交叉验证把数据分成 K 份，轮流做验证集，评估结果更稳定。时间序列数据要按时间切分，不能随机打乱，否则会造成数据泄漏。

## 五、深度学习基础

**神经网络**：多层感知机由输入层、隐藏层、输出层组成，每层做线性变换后接非线性激活函数。常用激活函数有 ReLU、Sigmoid、Tanh、GELU。

**反向传播与梯度下降**：用链式法则从输出层向输入层逐层计算梯度，再沿梯度反方向更新参数，这套迭代方法统称梯度下降。按每次使用的样本量分为批量梯度下降、随机梯度下降 SGD 与小批量梯度下降。学习率决定步长，过大会震荡发散，过小则收敛缓慢。常见改进优化器有 Momentum、RMSProp、Adam。

**训练技巧**：权重初始化（Xavier、He）、批归一化、Dropout、学习率调度、早停。

**卷积神经网络 CNN**：用卷积核提取局部特征，配合池化降采样，适合图像任务。

**循环神经网络 RNN**：按时间步处理序列，存在长程依赖问题，LSTM 与 GRU 用门控机制缓解。

## 六、Transformer 与注意力机制

Transformer 抛弃了循环结构，完全基于注意力机制建模序列，是当前大语言模型的基础架构。

**自注意力 Self-Attention**：输入序列的每个位置同时投影出三个向量——Query（查询）、Key（键）、Value（值），简称 Q、K、V，三者合称 QKV 三元组。用 Query 与所有 Key 做点积得到相关性分数，除以 √d_k 缩放防止梯度消失，经 Softmax 归一化后作为权重，对 Value 加权求和得到该位置的输出。Q、K、V 三个矩阵的作用不同：Q 表示「我在找什么」，K 表示「我能提供什么」，V 表示「我实际携带的信息」。三者由同一输入经不同权重矩阵线性变换而来，这正是需要三个矩阵的原因——如果共用同一个表示，就无法同时承担查询与被查询两种角色。

**多头注意力 Multi-Head Attention**：把 Q、K、V 投影到多个低维子空间并行计算注意力，再拼接输出。不同的头可以关注不同的模式，例如语法依赖、指代关系、位置邻近。

**位置编码 Positional Encoding**：注意力本身没有顺序概念，需要额外注入位置信息，常用正弦余弦编码或可学习的位置嵌入。

**残差连接与层归一化**：每个子层输出与输入相加，再做 LayerNorm，保证深层网络可训练。

**编码器与解码器**：编码器堆叠自注意力与前馈网络；解码器额外加入掩码自注意力与编码器-解码器交叉注意力。GPT 系列采用纯解码器结构，BERT 采用纯编码器结构。

## 七、工程实践要点

数据预处理流程：缺失值处理、异常值检测、类别特征编码（One-Hot、目标编码）、数值特征标准化。

特征工程：特征构造、交叉特征、特征选择。特征质量往往比模型选择更影响最终效果。

实验管理：固定随机种子、记录超参数、保存验证集指标，保证结果可复现。
