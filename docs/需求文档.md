**项目定位：** 面向高校学生的个人 AI 学习成长管理平台

------

# 1. 项目概述

## 1.1 项目背景

当前高校学生通常使用多个工具管理自己的学习：

- 课程表记录课程
- Excel 记录成绩
- 手机备忘录记录任务
- Markdown/Word 记录学习笔记
- LeetCode 记录算法题
- GitHub 记录项目
- 网盘保存课程资料

这些数据彼此独立。

学生可以知道：

> “我今天学了什么。”

但很难知道：

> **“我现在到底掌握了什么？”**

更加难以回答：

> **“我下一步最应该学什么？”**

传统学习管理软件主要解决“记录”问题，而不是“理解”和“决策”问题。

因此，本项目希望构建一个以 AI Agent 为核心的个人学习成长系统。

------

# 2. 项目目标

系统通过收集学生的：

- 学习记录
- 课程信息
- 学习笔记
- 错题记录
- 任务完成情况
- 学习时间
- 能力评估结果

建立用户的**个人学习画像**。

AI Agent 根据这些数据：

1. 分析学习状态
2. 发现知识薄弱点
3. 分析学习习惯
4. 制定学习计划
5. 动态调整学习计划
6. 回答学习问题
7. 总结阶段性学习成果
8. 预测潜在学习风险

最终形成：

> **记录 → 分析 → 规划 → 执行 → 反馈 → 再规划**

的闭环。

------

# 3. 产品核心理念

项目不是简单的：

> **AI + 聊天机器人**

而是：

> **AI Agent + 学习数据 + 知识库 + 个性化决策**

核心目标是让 AI 从：

**“回答问题”**

升级为：

**“帮助学生完成学习任务。”**

# 14. 动态学习计划

这是区别于普通 Todo App 的关键功能。

例如：

原计划：

```
周三：
完成 Transformer Attention
```

用户没有完成。

Agent 发现：

```
任务未完成
+
截止时间临近
+
近期学习时间不足
```

Agent 自动调整：

```
原计划

周三
Transformer
 ↓
未完成

重新规划

周六
14:00
Transformer

周日
19:00
知识点复习
```

并告诉用户：

> “检测到你本周 Transformer 学习任务未完成，我已经将任务调整到周六下午，并适当减少周六其他低优先级任务。”

这才体现 **Agent 的自主决策能力**。

# 15. 知识薄弱点分析

- 错题

- 用户自评
- 测试成绩
- AI 问答
- 重复提问

计算知识掌握情况。

例如：

```
Python             ██████████ 90%
数据结构           ████████░░ 80%
机器学习           ██████░░░░ 60%
线性代数           █████░░░░░ 50%
概率论             ████░░░░░░ 40%
```

AI 给出：

> 当前最需要加强的知识点是概率论。

# 16. 学习风险预警

例如：

```

↓

可能存在学习计划执行困难
```

**系统只做学习行为分析，不进行医疗或心理诊断。**

# 31. 项目创新点

## 创新点一：从“AI问答”变成“AI主动规划”

传统：

> 用户问 → AI回答

本项目：

> AI主动分析 → AI发现问题 → AI提出建议 → AI调整计划。

------

## 创新点二：建立个人学习数字画像

系统不只记录：

> “学了多久。”

而是建立：

> **“我是谁 + 我学过什么 + 我掌握什么 + 我正在学什么 + 我应该学什么。”**

------

## 创新点三：个人知识库 + 学习行为结合

传统 RAG：

> PDF → RAG → 问答

本项目：

> **个人知识库 + 学习行为 + 学习目标 + AI Agent**

因此 AI 的回答更加个性化。

------

## 创新点四：动态学习计划

不是生成一次计划以后就结束。

而是：

> **根据实际执行情况动态调整。**

这也是 Agent 与普通 AI 应用最重要的区别之一。

> **创建学习目标**

输入：

> 6个月掌握机器学习。

AI 自动拆解学习路线。

------

### 第二步

上传：

> 《机器学习笔记.pdf》

系统自动进入知识库。

------

### 第三步

告诉 AI：

> “我最近感觉机器学习学得很乱，你帮我分析一下。”

Agent 自动查询：

```
学习记录
+
任务
+
知识掌握度
+
知识库
```

然后给出：

> 你目前机器学习基础知识掌握较好，但数学基础不足，建议优先补充线性代数和概率论。

------

### 第四步

用户：

> “那帮我安排下一周。”

Agent 自动生成：

> 下周学习计划。

------

### 第五步

故意把一个任务设置成：

> **未完成**

再次询问：

> “我昨天的 Transformer 没学完怎么办？”

Agent 发现：

```
任务未完成
+
当前时间
+
其他任务
+
学习时间
```

自动重新规划。

------

### 最后

打开 Dashboard：

> **“这是 AI 根据我过去学习数据形成的个人学习画像。”**

这就是你们整个作品最有冲击力的一幕。

# 33. 项目最终一句话介绍

比赛答辩时，可以把项目概括成：

> **“彭城智学是一款面向高校学生的 AI 学习成长智能体。它通过整合学生的学习目标、任务、学习记录和个人知识库，构建个人学习画像，并利用 Agent 主动分析学习状态、制定和动态调整学习计划，最终形成从‘记录学习’到‘理解学习’，再到‘帮助学生持续成长’的 AI 学习闭环。”**
